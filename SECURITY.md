# Security Policy

## Private Reporting

Do not create public reports or external issues for security vulnerabilities.

This is a private, closed-source repository. Report security concerns only through a private direct channel with the repository owner.

## Project sensitivity

Blueprints handles:

- signed project data
- membership authority
- tamper detection
- audit history

Changes in these areas should be reviewed conservatively.

## Supported versions

This repository is pre-release. Security fixes, when applicable, will target the current `main` branch first.
