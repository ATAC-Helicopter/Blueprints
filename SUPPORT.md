# Support

Blueprints is currently a community-supported technical preview.

- Use a **bug report** for reproducible defects.
- Use a **feature request** for scoped product proposals.
- Use a **question** discussion when GitHub Discussions is enabled.
- Use private vulnerability reporting for security concerns.

Include the operating system, .NET SDK version, Blueprints commit/version, relevant logs, and sanitized reproduction steps. Never upload private keys, access tokens, or real confidential workspace content.

There is no guaranteed response time or production support commitment before v1.0.
